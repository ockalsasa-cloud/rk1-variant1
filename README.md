РК №1 - Вариант 1

Решения заданий по Python.

Задание 1

Функция chunk(items, size) разбивает список на части заданного размера. Тесты написаны с использованием pytest.

Задание 2

Исправлена гонка при работе с общим счётчиком. Для синхронизации потоков используется threading.Lock.

Задание 3

Модель Item и POST-запрос /items на FastAPI. При создании элемента ему присваивается id.

Запуск

Установить зависимости:

pip install -r requirements.txt

Запустить тесты:

python -m pytest

Запустить основную программу:

python main.py

### Запуск сервера

python -m uvicorn main:app --reload

После запуска документация API доступна по адресу:
http://127.0.0.1:8000/docs
